# Saira — Hausschrift (Brand & CI v2.1)

Saira ist die SwiPay-Hausschrift. Diese TTF-Schnitte liegen bewusst IM Repo,
damit das Kunden-PDF auf jedem Rechner identisch rendert und nicht vom
persönlich installierten Font-Ordner abhängt.

Eingebundene Schnitte (siehe `reporter.py`, `_register_fonts`):

| Datei                | Verwendung                                  |
|----------------------|---------------------------------------------|
| Saira-Regular.ttf    | Fliesstext, kleine Hinweise                 |
| Saira-Bold.ttf       | Labels, Sektionstitel, Hervorhebungen       |
| Saira-Italic.ttf     | Disclaimer                                  |
| Saira-ExtraBold.ttf  | Grosse Zahlen (Hero, Kacheln) — CI-Headline |
